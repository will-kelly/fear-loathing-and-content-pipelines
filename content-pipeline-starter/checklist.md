# The checklist

This is the gate. One person answers five questions, yes or no. All five yes: it ships. Any no: back to the draft.

**Who answers:** Priya Raman. If she's out, Will Kelly. Nobody else, and not the person who asked for the piece.

**How long it takes:** About five minutes. If it's taking longer, the draft is too long or the source file is unclear.

---

## The five questions

**1. Is every `[S]` fact actually in the source file, worded the way the file says?**
Open `sources/about-kestrel.md`. Check each one. The AI is usually right about this, but "usually" is why you're here.

**2. Has every `[?]` been dealt with?**
Either cut from the draft, or added to the source file by its owner. A `[?]` still sitting in the text is a no.

**3. Does the draft make the point the request asked for, and only that point?**
Reread the "Point" line on the request. If the draft drifted into something else, no.

**4. Is anything from "Must not say" in it?**
Including in softer wording. "Fully compliant" rephrased as "meets every requirement" is still a no.

**5. Would you put your name on it?**
Not "is it fine." Would you sign it. If you hesitate, that's a no, and the hesitation is the note you give back.

---

## What to do with the answers

**Five yes:** Copy the draft text (without the tags). Add a row to `log.md`. Ship it.

**Any no:** Tell the AI which number and why, in one line. It fixes that thing and shows you the checklist again. Don't fix the draft yourself; if you do, the AI can't retag it, and the next person doesn't know what changed.

## What this checklist is not

It isn't a style review. If you don't like a sentence, that's not a "no" unless it breaks question 3 or 5. The gate checks whether the piece is true and bounded. Taste is a separate conversation, and it shouldn't block shipping.

It isn't optional. "It's just a LinkedIn post" is how the wrong price gets published.
