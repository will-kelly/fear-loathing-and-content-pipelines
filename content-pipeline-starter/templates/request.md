# Request form

Fill this in before you ask the AI for anything. Half a page, five minutes. If you can't fill in "Point," you're not ready to ask for the piece yet, and that's useful to know now rather than after three drafts.

```
Piece name:     (short, lowercase, hyphens: kestrel-soc2-linkedin)
Requested by:
Date:

Channel:        (LinkedIn post / short email / blog intro)
Audience:       (who reads it; be specific: "security leads evaluating us," not "customers")
Point:          (ONE sentence. What should the reader believe after reading?)

Must include:   (facts that have to be in it; each one should be in the source file)
  -
  -

Must not say:   (anything off-limits for this piece)
  -

Length:         (LinkedIn 100-180 words / email 80-150 / blog intro 150-250)
```

## The "Point" line is the whole form

Everything else is logistics. "Point" is what makes the task bounded. Compare:

- **Topic (not ready):** "Something about our SOC 2."
- **Point (ready):** "A security review of Kestrel can start from our SOC 2 report instead of a questionnaire."

The first one could produce fifty different drafts and you'd have no way to say which was right. The second one, you can check a draft against in ten seconds.

## "Must include" should be short

Two or three facts. If you have six, you're writing a brochure, not a post. And every one should already be in the source file. If it isn't, go get it added first.
