# Draft layout

This is what the AI hands back. You don't fill it in; it's here so you know what to expect and what each part is for.

```
## Draft

(the text, with [S] and [?] tags after each fact)

## Where each fact came from

| Fact | Tag | Source section |
|---|---|---|
| ... | [S] | Security |
| ... | [?] | not in source |

## Things I couldn't source

- "..." [?]: not in the source file. Cut it, or ask Priya to add it.

## Word count

N (target: N to N)
```

## Reading the tags

`[S]` means "I found this in the source file, in the section named in the table." You still check it (checklist question 1), but you know where to look.

`[?]` means "I wrote this and I can't back it up." The AI is allowed to write a `[?]` sentence; it's not allowed to hide one. Every `[?]` is a decision for you: cut it or get it added to the source.

A draft with zero `[?]` tags on the first try is either a very simple piece or an AI that isn't being honest about its tags. Spot-check it.

## Before you copy the final text

Strip the tags. They're for you, not the reader.
